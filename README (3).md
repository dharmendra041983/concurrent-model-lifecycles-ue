# Paper mapping

Manuscript: **Concurrent Model Lifecycles at the UE: Interaction Between Beam Management, CSI Prediction, and CSI Compression**

Target venue: IEEE Transactions on Wireless Communications (TWC).

The manuscript PDF/source is intentionally not duplicated in this software
release. `artifact_manifest.yaml` maps every reported table/figure to the
script that produces the corresponding result. Aggregate values transcribed
from the submission manuscript are under `results/paper_reported/`; they are
checks, not raw simulation outputs.

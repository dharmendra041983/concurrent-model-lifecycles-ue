# Execution environment used for the final runs

Recorded from the author's final experiment environment:

- Python: 3.12.14
- PyTorch: 2.14.0+cu130
- PyTorch CUDA runtime: 13.0
- Sionna: 2.0.1
- GPU: NVIDIA GeForce RTX 5070 Laptop GPU (12 GB class)
- NVIDIA driver: 592.25 (driver reports CUDA 13.1 support)

The paper makes no training-time or inference-latency claim. Hardware is
recorded for reproducibility, not as a performance result.

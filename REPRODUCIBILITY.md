# Reproducibility Notes

## Final experiment configuration

- Sionna 2.0.1; Python 3.12.14; PyTorch 2.14.0+cu130.
- FR2: CDL-B, 28 GHz, 120 kHz SCS, 30 ns delay spread, 4x8 BS, 1x2 UE.
- FR1: CDL-C, 3.5 GHz, 30 kHz SCS, 300 ns delay spread, 2x8 BS, 1x2 UE.
- UE speed uniform on [1,15] m/s; 200-slot episodes; randomized orientation.
- Oversampled DFT codebook: 128 beams FR2, 64 beams FR1; Set B is 25%.
- Predictor: GRU-128, W=8, horizon k=2.
- Compressor: latent 16 x 4 bits = 64 bits; fallback = 12-bit wideband report.
- Training: 1024 train / 128 validation realizations, Adam 1e-3, batch 64, 200 epochs.
- Beam/predictor validation every 10 epochs with best evaluated checkpoint retained; compressor uses final epoch.
- Beam weight decay 1e-4; predictor 1e-5; compressor 0.
- Lifecycle: q_enter=3, q_exit=25, 5% nominal per-pipeline threshold calibration on 64 realizations.
- Statistics: realization-level paired comparisons; 95% percentile bootstrap; 10,000 resamples; Holm correction for four planned subset comparisons.

## Reproduction policy

Channel caches are intentionally not distributed. The code seed-addresses each
realization so the channels can be regenerated. Raw JSON outputs are also not
pre-populated in this package; the full-run scripts regenerate them into
`results/raw/`. Compact aggregate values from the manuscript are included only
as post-run checks.

## Checkpoints

Model checkpoints are regenerated by `src/train.py` and `src/train_pair.py`.
They are not required in the archive if the retraining path is available and the
execution environment is recorded.

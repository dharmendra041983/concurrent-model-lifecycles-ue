# Execution environment

Environment confirmed from the final experiment machine:

- Python 3.12.14
- PyTorch 2.14.0+cu130
- PyTorch CUDA runtime 13.0
- Sionna 2.0.1
- NVIDIA GeForce RTX 5070 Laptop GPU
- 12 GB GPU memory
- NVIDIA driver 592.25
- Driver-reported CUDA support 13.1

The driver-supported CUDA version and the CUDA runtime used by PyTorch are
reported separately because they are not the same quantity.

No training-time or inference-latency benchmark is claimed for this study
unless a dedicated timing run is added later.
